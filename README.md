# 🚢 Titanic Survival Prediction

A machine learning project that predicts whether a passenger would survive the Titanic disaster using **Logistic Regression**.

This project covers the complete machine learning workflow — from **data cleaning and preprocessing** to **model training, evaluation, and prediction**. It also includes interactive HTML pages for exploring the cleaned dataset and making survival predictions.

---

## 📌 Project Overview

The Titanic dataset is one of the most commonly used datasets for learning machine learning.

It contains information about **891 passengers**, including their passenger class, age, fare, gender, and survival status.

The goal of this project is to train a **Logistic Regression** model that predicts whether a passenger survived based on:

* Passenger Class
* Age
* Fare

The model can also provide the **probability of survival** for a new passenger.

---

## 📌 Dataset Note

The Titanic dataset used in this project is a **historical dataset commonly used for machine learning training and educational purposes**.

This project is intended **only for learning, experimentation, and demonstrating machine learning concepts**. The predictions generated by the model are not real-world predictions and should not be considered historically accurate predictions of individual passengers.

The dataset is used to practice:

* Data cleaning
* Data preprocessing
* Feature selection
* Logistic Regression
* Model evaluation
* Making predictions on new sample data

## 🧹 Data Cleaning & Preprocessing

The raw Titanic dataset contains missing values and inconsistent data. The `ship.py` script prepares the data for machine learning.

### Cleaning steps:

* **Age** → Missing values filled with the average age (~29.7 years)
* **Embarked** → Missing values filled with the most common port (`S`)
* **Cabin** → Missing values replaced with `"Unknown"`
* **Siblings_Spouse** → Missing values filled with `0`
* **Parents_Children** → Missing values filled with `0`
* **Duplicate rows** → Removed
* **Age** → Converted from float to integer
* **Column names** → Renamed for better readability
* **Gender** → Converted to lowercase
* **Embarked** → Converted to uppercase

After cleaning, the processed data is saved as:

```text
titanic.csv
```

## 🤖 Machine Learning Model

This project uses **Logistic Regression**, a supervised machine learning algorithm commonly used for binary classification problems.

### Features

The model uses three features:

```text
Passenger_Class
Age
Fare
```

### Target

```text
Survived
```

Where:

```text
0 = Did not survive
1 = Survived
```

## ⚙️ Model Workflow

The machine learning process follows these steps:

```text
Raw Titanic Data
       ↓
Data Cleaning
       ↓
Cleaned Dataset
       ↓
Select Features & Target
       ↓
Train/Test Split
       ↓
Logistic Regression
       ↓
Model Evaluation
       ↓
New Passenger Input
       ↓
Survival Prediction
```

### Train/Test Split

The dataset is divided into:

* **80% Training Data**
* **20% Testing Data**

The model is trained on the training data and evaluated using the testing data.

## 📊 Model Evaluation

The model's performance is evaluated using **accuracy score**.

Accuracy measures how many predictions the model classified correctly out of all test samples.

The project also uses the trained model to calculate the **probability of survival** for a new passenger.

Example:

```text
Survival Probability: 68.5%
```
